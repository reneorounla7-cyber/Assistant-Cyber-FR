# 🛡️ Assistant Cyber FR

## À propos

Assistant Cyber FR est un projet Python destiné à aider les débutants à apprendre les bases de la cybersécurité en français.

## Fonctionnalités

- Vérification de la force d'un mot de passe
- Conseils de cybersécurité
- Détection de mots de passe faibles
- Génération de mots de passe sécurisés
- Informations sur les attaques de phishing
- Conseils pour protéger son ordinateur

## Technologies

- Python
- Git
- GitHub
